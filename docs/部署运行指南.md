# 翰墨裂变 · 部署运行指南

## 环境要求
- **Node.js ≥ 22.x**（代码使用内置 `node:sqlite`，Node 22 才稳定；Node 16/18/20 启动会报 `Cannot find module 'node:sqlite'`）
- npm ≥ 8

## 安全配置（上线前必做）
1. 设置环境变量 `JWT_SECRET`（32 位以上随机字符串），未设置时系统首次启动会自动生成并持久化；
   同时通过 `CORS_ORIGINS` 配置前端域名白名单（逗号分隔），如：`CORS_ORIGINS=https://your.domain.com`
2. 登录/注册已要求手机号 + 密码；老账号（无密码）需管理员在「用户管理」中重置密码
3. 管理后台默认密码 `admin/admin123`，**上线前务必修改**（修改 `admin_auth.password_hash` 或后续新增改密入口）
4. 后台路径前缀可在「参数配置」中修改，防止路径被爆破

## 一、启动后端
```bash
cd server
npm install
npm run dev
```
- 首次启动自动建库建表（`server/data/hanmo.db`）
- 服务地址：http://localhost:3000
- 仅初始化数据库（不启动服务）：`npm run init`
- 定时任务统一使用北京时间；进程凌晨重启会自动补跑当日考核与当月结算

## 二、启动前端
```bash
cd web
npm install
npm run dev
```
- 访问 http://localhost:5173
- 已配置 /api 与 /uploads 代理到后端 3000

## 三、测试分销闭环（可选）
```bash
cd server
node seed.js
```
- 会生成一个模拟分销链：主理人→学员→管培生
- 验证介绍奖、培育奖、10%待遇、考核结算

## 四、账号
- 管理后台：http://localhost:5173/admin
  - 账号 admin / admin123

## 五、核心功能验证路径
1. 注册两个用户，第二个填第一个的推荐码
2. 用推荐用户购买499课程 → 推荐人获得100元介绍奖（可在「我的」查看）
3. 升级为推广身份（需先付费），介绍2人成交 → 形成管培生名额
4. 管理后台执行"每日考核+待遇结算" → 看待遇生成
5. 把某管培生业绩清零连续2月 → 触发清退+30天补位倒计时
6. 体验课预约：首页点"免费体验课预约"
7. 拼团：首页"去拼团" → 开团/参团（仅学习优惠，不产生奖励）
8. 规则公示：首页底部"规则" → 切换"极简用户版/完整官方版"
9. 补位预警：管培生未达标时，「我的」会收到系统提醒（不补位冻结收入）
10. 双用户隔离：纯学习用户无推广权限，需先付费才能升级为推广身份

## 六、目录结构
```
server/
  src/
    db.js       # 数据库初始化、建表、默认配置
    engine.js   # 奖励结算引擎（介绍/帮扶/待遇/考核/清退/补位）
    cron.js     # 定时任务（每日考核、每月重置、每月待遇结算）
    auth.js     # JWT 认证
    index.js    # Express 入口 + 全部 API
  seed.js       # 测试种子数据
web/
  src/
    views/      # 页面
    views/admin/ # 管理后台页面
    store.js    # Pinia 状态
    api.js      # axios 封装
    router.js   # 路由
```

## 七、生产环境注意
- 修改 `server/src/auth.js` 中的 SECRET
- **必须单进程运行**：生产环境使用 `node src/index.js`（或 PM2 单实例 `pm2 start src/index.js -i 1`），**禁止 pm2 cluster / 多进程模式**。SQLite 不支持多进程并发写入，多进程会导致数据库锁死、数据错乱
- 正式部署后**第一时间修改默认管理员密码** `admin/admin123`（服务启动时会检测并在日志打印警告）
- SQLite 适合 MVP；正式上线建议迁移 MySQL
- 需对接真实微信支付/短信/域名 HTTPS
- 上线前请专业法律人士复核商业模式合规性

## 八、业务约束与能力决策（已确认）
### 1. 退款佣金处理规则
- 退款时对应奖励流水标记 `refunded`，**未提现**的余额自动剔除该部分奖励
- **已提现**的资金无法自动追回，依靠 `pay_logs` 对账日志人工核对、线下协商处理
- 该业务约束需在后续版本补充到用户端/后台相关说明文案

### 2. 微信内容安全（msgSecCheck）暂不接入
- 当前版本不做微信内容安全接口调用，帖子内容**先审后发**（后台审核通过才展示）
- 后续发布微信小程序版本时，配置小程序 `appid/secret` 后再开启该能力
- 属于迭代计划项，不在本阶段实现范围
