

书法小程序｜最终极简开发落地文档（可直接交付技术）
一、项目整体架构（双用户体系｜核心重点）
两类用户完全隔离、独立运行、互不干扰
1. 纯学习用户（传统家长）：只可学习、打卡、任务、拼团，无任何推广、奖励、学习圈权限
2. 创业推广用户（学员/管培生/主理人）：可推广、可孵化、可拿奖励、可做学习圈管道收益
全局合规：仅两级分享、无多层级、无人头费、真实教学交付
二、后台【可视化可自定义参数】（全部无需改代码）
所有数值后台可随时修改、实时生效
1. 产品价格配置
499基础班 / 1299进阶班 / 2999终身班 售价、权益、有效期可自定义
2. 奖励参数配置
介绍奖励（默认100）、培育奖励（默认200）、高阶产品奖励比例可自定义
3. 考核规则配置
零业绩清退周期（默认2个月）、补位时效（默认30天）、单名额最大补位次数（默认2次）、主理人停待遇无业绩月份（默认3个月）、管培生达标业绩门槛可自定义
4. 营销工具配置（家长端）
拼团人数、拼团时长、拼团优惠；打卡/任务单次抵现金额、每日上限、抵现过期时间、可抵扣场景
三、核心业务逻辑（强制锁死、合规闭环）
1. 管培生机制
管培生无底薪、零业绩零收入
连续2个月零业绩 → 自动清退出人才库 → 对应主理人该名额待遇冻结
清退后30天内主理人需补推1名合格管培生，超时未补位，名额永久作废
单个孵化名额最多补位2次，第2次淘汰后永久失效，不再补位
2. 管培生月度状态判定
合格：月业绩≥1000或2单及以上 → 全额个人收益 + 计入主理人待遇
见习：有业绩但未达标 → 个人奖励减半、不计学习圈待遇
失效：0业绩 → 当月零收益、冻结岗位权益
3. 主理人待遇机制
仅【合格管培生】当月业绩产生10%终身学习圈待遇
见习/零业绩/已清退名额无待遇
主理人连续3个月无学习圈有效业绩，整体待遇暂停发放
4. 培育奖机制
成功孵化2名合格有效管培生，解锁200元培育奖
中途名额淘汰未补位达标，不发放奖励
四、前台营销工具（纯家长学习体系、合规无风险）
所有营销福利资金禁止提现、禁止退款、禁止折现
1. 每日打卡赚抵现金
练字打卡、课堂签到、学情复盘可累积抵现金
仅可用于：课程续费、课程升级、线下活动、学习物料抵扣
2. 学习任务中心
纯学习任务（无拉新推广）：看课、交作业、作品上传、学情自评、公益课预约
完成任务自动发放抵现金
3. 课程拼团功能
2-3人家长拼团购课，享受专属优惠
拼团仅学习优惠，不产生任何奖励、学习圈收益，完全隔离裂变体系
五、收益结算规则（全自动）
介绍奖励：成交实时到账、可提现
培育奖励：孵化达标一次性发放
主理人终身待遇：月度结算自动发放
学习抵现金：仅消费抵扣，永不提现
六、小程序页面清单（最简版）
首页、免费体验课预约、课程购买、拼团专题页、学习任务中心、个人中心、奖励明细、孵化进度、管培生状态、主理人学习圈后台、规则公示页
七、全局合规底线（开发必须死守）
1. 付费全部为教学服务费，推广权益为平台赠与，非加盟收费
2. 仅两级分享，无多级躺赚层级
3. 所有学习圈收益必须绑定「服务+业绩」，零产出零收益
4. 学习抵现资金闭环，无资金提现流出风险
5. 双用户体系彻底隔离，普通家长无任何裂变压力
