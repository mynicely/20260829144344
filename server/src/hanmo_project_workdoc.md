### UI优化｜课程列表页 `/courses` 布局改版｜中优先级
## 现状问题（截图）
当前PC端课程列表是双列多卡片网格布局，卡片内部按钮拥挤，3个按钮挤在同一行，空间局促，视觉杂乱不好看；移动端参考图是单列布局，希望PC端课程列表对齐这套审美风格。

## 修改需求
1. 布局切换：`/courses`课程列表页面，**取消双栏网格，改为单列流式布局，一行只展示1个课程卡片**，卡片宽度占满容器有效宽度。
2. 卡片内部结构对齐移动端参考样式：
- 上方：课程封面大图（横向宽图，不要小方图）
- 中间区域：课程标题、简介、价格、原价、标签（拼团/可砍价标签放在标题旁边）
- 下方：操作按钮组
3. 按钮排版规则：
- 主按钮【立即报名】使用主色`--color-cinnabar`，尺寸更大；
- 【发起拼团】【发起砍价】放在右侧，次要样式；
- 按钮不要挤压堆叠，留出足够间距；后端配置没有开启的营销项，直接隐藏对应按钮。
4. 响应式兼容：
- PC端：单列，大卡片横向排版；
- 手机移动端：保持单列自适应，和截图里手机端课程页面视觉风格统一。
5. 原有全部业务逻辑保留：按钮点击跳转、拼团砍价开关、角标、价格渲染**逻辑完全不动，仅调整CSS布局和排版**。

## 约束
1. 只修改前端页面布局CSS与DOM结构，**接口、后端逻辑全部不变**。
2. 课程详情页不受本次改动影响。

## 自测验收点
- [ ] PC访问/courses，一行只显示1个课程卡片，不再两列并排。
- [ ] 封面为宽幅横向大图，不再是小方块封面。
- [ ] 卡片内部信息层级清晰，按钮布局宽松不拥挤。
- [ ] 拼团/砍价配置开关正常生效，不支持的按钮自动隐藏。
- [ ] 手机端访问，自适应单列，样式和手机端参考截图风格统一。

### 任务3 ✅｜UI优化｜课程列表页 `/courses` 布局改版（双列网格 → 单列大卡片）

**性质**：纯前端页面布局 CSS 与 DOM 结构调整；接口、后端逻辑零改动；课程详情页不受影响；`<script>` 业务逻辑一行未动。

**改动文件**：`web/src/views/Courses.vue`（仅此一个文件）

**实现内容**：
1. **布局切换（单列流式）**：`.goods-grid` 双列网格 → `.courses-list`（`flex-direction: column; gap: 16px`），一行只显示 1 个课程卡片，卡片宽度占满容器有效宽度。
2. **卡片结构对齐移动端参考**：
   - 上方：封面大图，封面比例由 4:3 小方块 → **16:9 横向宽图**（PC 左栏 16:10）；无图时保留渐变占位 `cover-fallback`；

4. **响应式**：

   - 手机（<768px）：单列自适应，封面上横图 + 信息下方，与手机端参考截图风格统一。
5. **业务逻辑完全保留**：`jumpBuy`（立即报名 → 详情页 `?buy=1` 唤起二选一弹窗）、`goGroup`、`startBargain`（promoter 确认弹窗 + `/bargain/start`）等 script 代码零改动；角标/标签显示条件、价格 `fmtMoney` 渲染逻辑原样。
